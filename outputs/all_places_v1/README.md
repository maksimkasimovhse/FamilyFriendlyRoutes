# Датасет всех мест

**1 258 записей, 10 категорий.** Это полный справочник доступных в проекте мест:
174 строки `main`, 85 строк `addition` и 1 000 объектов OSM. Один известный дубль
парка «Швейцария» объединён, обе исходные строки сохранены. Дополнительный CSV
пользователя повторяет 259 исходных записей и не увеличивает число мест.
Возможные пересечения CSV и OSM сохранены с `possible_duplicate_ids` для проверки.
Число строк не является подтверждённым количеством уникальных физических объектов.

## Файлы

- `places.csv` — полный плоский датасет, UTF-8 с BOM, разделитель — запятая.
- `places.jsonl` — тот же справочник с вложенными evidence, исходными строками и OSM-тегами.
- `places.xlsx` — основные поля для просмотра и фильтрации в Excel; лист «О данных» объясняет состав.
- `source_mapping.csv` — соответствие каждой исходной записи итоговому ID, включая aliases и повторную выгрузку.
- `report.json` — категории, заполненность, статусы описаний и SHA-256 входов и выходов.
- `description_queue.csv` — результат обработки каждого из 1 000 объектов OSM, ссылки и типы ошибок.
- `description_report.json` — сводка восстановления описаний.

В CSV вложенные значения записаны JSON-строками, неизвестные скаляры — пустыми
ячейками. В JSONL неизвестные скаляры — `null`. Строки CSV, начинающиеся с символов
формулы Excel, защищены апострофом; JSONL сохраняет исходные значения без этой защиты.
Координаты разделены на `longitude` и `latitude`, WGS84.

## Описания из открытых источников

Использован существующий HTML-fetcher, нормализация страниц и GigaChat-парсер.
Запущены 162 URL для 192 объектов OSM: сайты из OSM и найденные по названиям
страницы. Получены тексты 63 страниц; полный структурированный LLM-разбор успешен
для 57. Остальные результаты содержат явные ошибки DNS, HTTP, robots, TLS либо
извлечения. Robots-запреты не обходились.

Дополнительно HTML-парсер прошёл все 27 страниц публичного туристического
каталога [Туристический Нижний Новгород](https://nn-grad.ru/kuda-poyti/): 205 карточек
и 30 подробных страниц найденных совпадений. Сопоставление использует название
и расстояние до 300 м. Неоднозначные и нечёткие совпадения оставлены кандидатами.
Для музея живой бумаги сайт обнаружен по названию в муниципальном справочнике;
страницу загрузить не удалось. Поиск через Wikipedia API вернул HTTP 403,
энциклопедические тексты в датасет не добавлялись.

**60 объектов получили описание из страниц сайтов**; для 59 из них описание ранее
отсутствовало. С учётом исходных текстов OSM описания есть у 109 из 1 000 объектов.
В общем датасете с CSV заполнены **367 описаний из 1 258**.
891 запись пока без описания: 394 требуют поиска источника, у 104 источник не получен,
18 — проверки соответствия странице, 15 — подходящего описательного текста,
360 — поиска по местоположению, поскольку названия отсутствуют.
Всего в исходном OSM 363 объекта без собственного имени; у трёх уже было описание.

`description` содержит исходный текст или точный фрагмент страницы, а не свободный
пересказ модели. `description_evidence` сохраняет цитату, URL, время получения,
часть источника и, для HTML, SHA-256. У записей OSM остаются оригинальные теги и URL.
Часть автоматических фрагментов проверена и заменена по
`data/site_collection/osm_description_review.json`: отзывы, биографии сотрудников,
маркетинговые футеры и анонсы мероприятий не использованы как описание места.

`description_origin`: `seed_description`, `osm_description`, `parsed_site_excerpt`,
`parsed_tourism_card`, `parsed_tourism_detail` либо `unknown`.
`description_status` показывает исходный текст, восстановление, ошибку или необходимую проверку.
Описание сети помечено `scope=brand` и не подтверждает условия отдельного филиала.
`description_candidates` сохраняет и альтернативные фрагменты, требующие проверки.
Отзывы Geo Reviews в качестве описаний **не используются**.

## Остальные поля и границы использования

Категории: достопримечательности 356, еда 309, площадки 165, скамейки 100,
прочее 89, музеи 74, туалеты 65, культурные площадки 39, укрытия 38, парки 23.
`event` обозначает культурную площадку, а не подтверждённое мероприятие с сеансом.

Сохранены адреса, координаты, исходные категории, сайты и телефоны, сырые часы,
доступ, платность и доступность колясок из OSM, известные булевы признаки,
эвристические темы и форматы, принадлежность и причина статуса в MVP.
Неизвестные длительности, возраст, цены и правила не заполнены догадками.
Часы из OSM не равны проверенному расписанию; текст сайта — утверждение источника,
а `facts_checked_at` остаётся `null`. Адреса могут быть неполными, координаты не
проверены как точки входа. В исходниках есть и объекты за пределами городского MVP.

281 место отмечено `in_mvp=true`. Этот экспорт не меняет активный каталог маршрутизатора.
Датасет является справочником с источниками, а не размеченной обучающей выборкой
возрастной пригодности или пользовательских предпочтений.

Атрибуция геоданных: © OpenStreetMap contributors, ODbL 1.0.
У текстов внешних сайтов сохраняются ссылки и происхождение; общая лицензия
на свободное переиспользование этих текстов не устанавливалась.

## Повторный запуск из корня репозитория

```bash
.venv/bin/python scripts/restore_osm_descriptions.py --workers 6
.venv/bin/python scripts/discover_tourism_descriptions.py
.venv/bin/python scripts/recover_osm_descriptions.py
.venv/bin/python scripts/export_all_places.py
PYTHONPATH=models:scripts .venv/bin/python -m unittest discover -s scripts -p test_osm_descriptions.py
```

Коллекторы переиспользуют успешные снимки из `data/processed/site_collection/`.
Первый запускается с уже настроенными GigaChat-переменными из локального `.env`;
ключи в экспорт не попадают. Последние два шага выполняются без сети.
