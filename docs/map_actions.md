# Изменение маршрута с карты

Входы: сценарии в строке под картой и поле «Изменить маршрут» под карточкой дня. Отдельная вкладка помощника удалена из интерфейса и графа загрузки приложения.

## Срочные действия

Сценарии: ребёнок устал, туалет, аптека, поесть, дождь, площадка, пропуск следующей точки. Поиск использует GPS и реальные объекты PostgreSQL, возвращает три ближайших без ограничения радиусом. Для дождя отбираются подходящие укрытия. Без разрешения на геолокацию показывается ошибка; старт вместо GPS не подставляется.

Карточка показывает название, расстояние по прямой и «Зайти сюда». Нажатие сразу рассчитывает preview по OSM, без отдельной кнопки выбора. На карте показывается предложенная геометрия; в виджете — добавленные/удалённые остановки, изменение времени и ходьбы, предупреждения. Сохранение — по «Применить маршрут»; отмена — «Оставить как было».

Объект добавляется первой из оставшихся остановок. Координаты берутся сервером из базы по ID. История и другие дни сохраняются. Перед расчётом обновляется GPS; в активном дне путь от последней подтверждённой точки до GPS оценивается по OSM, расходует время и сопровождается предупреждением. Это оценка движения, а не GPS-трек.

Оценочная длительность захода: аптека 15 минут, туалет 10, еда 45, скамейка 10, парк 15, площадка 20. Автоматического резерва на еду и отдых нет. Если пользователь выбрал кафе или отдых, учитывается только длительность этой остановки. Неподтверждённые часы работы требуют предупреждения. Выход за пользовательский бюджет времени запрещает применение; другие точки автоматически не удаляются. Заход не расходует квоту ручных туристических карточек.

Пропуск следующей точки не требует GPS: используется последняя подтверждённая позиция. Обязательные и посещённые остановки защищены.

## Текстовые изменения

Поддерживаются: «убери следующую точку», «убери последнюю точку», удаление по названию, «сократи прогулку», «пересчитай маршрут» и поиск туристических мест: например, «хочу посмотреть кремль» или «добавь что-нибудь про историю». При поиске помощник возвращает до трёх реальных кандидатов из каталога. Пользователь выбирает один, после чего backend строит preview добавления; до нажатия «Применить маршрут» поездка не меняется. Срочные запросы вроде «нужна аптека» открывают поиск ближайших объектов. Неоднозначные и неподдерживаемые команды возвращают ошибку с примерами.

Генеративный ИИ пока не подключён: используется ограниченный разбор команд. Все изменения проходят через preview/apply с проверками владельца, версии и бюджета. Старые модули assistant не загружаются приложением.

## Контракт и проверка

В OpenAPI `PlanCommand` добавлены `insert_infrastructure_stop` (date, place_id, опционально position и observed_at) и `edit_route` (date, text). Используются существующие endpoints preview/apply.

Go-тесты проверяют историю, GPS-расход, другие дни, дубли, права владельца, отсутствие записи при preview и конфликт версии. `node scripts/smoke-map-actions.mjs` проверяет живые сервисы: три аптеки PostGIS → OSM-заход → apply → текстовое удаление.

## Панель карты

В строке только «Скамейка», «Туалет», «Аптека», «Поесть», «Парки», «Площадки», «Пропустить точку». Категории фильтруют метки объектов на карте: нет поиска трёх ближайших, списка результатов, GPS-перехода к ним или вставки в маршрут. Категории независимы и объединяются: можно одновременно включить туалеты, аптеки и другие слои. Повторное нажатие выключает только эту категорию; без выбранных категорий видны все объекты. Скамейки загружаются только в пределах 125 м от геопозиции; остальные объекты — в коридоре 125 м у маршрута. «Пропустить точку» отдельно использует preview/apply с сохранением истории. В подтверждении только изменение общей длительности («Маршрут сократится на …») и кнопки отмены/применения. Подтверждения предупреждений передаются автоматически при нажатии «Применить маршрут»; запрет can_apply сохраняется. Текстовое редактирование маршрута сохраняется. Старый API insert_infrastructure_stop остаётся совместимым, но из строки категорий не вызывается.

Под фильтрами находится «Детский режим». Панель сворачивается и разворачивается стрелкой. Погода полностью удалена из интерфейса: иконка, блок на экране дня и запросы прогноза.

При пересчёте неначатого дня в режиме in_city старт в прошлом переносится на текущее время, время окончания не увеличивается.
