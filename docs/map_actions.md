# Изменение маршрута с карты

Входы: плавающий виджет «Нужно сейчас» и поле «Изменить маршрут» под карточкой дня. Отдельная вкладка помощника удалена из интерфейса и графа загрузки приложения.

## Срочные действия

Сценарии: ребёнок устал, туалет, аптека, поесть, дождь, площадка, пропуск следующей точки. Поиск использует GPS и реальные объекты PostgreSQL, возвращает три ближайших без ограничения радиусом. Для дождя отбираются подходящие укрытия. Без разрешения на геолокацию показывается ошибка; старт вместо GPS не подставляется.

Карточка показывает название, расстояние по прямой и «Зайти сюда». Нажатие сразу рассчитывает preview по OSM, без отдельной кнопки выбора. На карте показывается предложенная геометрия; в виджете — добавленные/удалённые остановки, изменение времени и ходьбы, предупреждения. Сохранение — по «Применить маршрут»; отмена — «Оставить как было».

Объект добавляется первой из оставшихся остановок. Координаты берутся сервером из базы по ID. История и другие дни сохраняются. Перед расчётом обновляется GPS; в активном дне путь от последней подтверждённой точки до GPS оценивается по OSM, расходует бюджет и сопровождается предупреждением. Это оценка движения, а не GPS-трек.

Оценочная длительность захода: аптека 15 минут, туалет 10, еда 45, скамейка 10, парк 15, площадка 20. Автоматического резерва на еду и отдых нет. Если пользователь выбрал кафе или отдых, учитывается только длительность этой остановки. Неподтверждённые часы работы требуют предупреждения. Выход за бюджет запрещает применение; другие точки автоматически не удаляются. Заход не расходует квоту ручных туристических карточек.

Пропуск следующей точки не требует GPS: используется последняя подтверждённая позиция. Обязательные и посещённые остановки защищены.

## Текстовые изменения

Поддерживаются: «убери следующую точку», «убери последнюю точку», удаление по названию, «сократи прогулку», «пересчитай маршрут». Срочные запросы вроде «нужна аптека» открывают поиск. Неоднозначные и неподдерживаемые команды возвращают ошибку с примерами.

Генеративный ИИ пока не подключён: используется ограниченный разбор команд. Все изменения проходят через preview/apply с проверками владельца, версии и бюджета. Старые модули assistant не загружаются приложением.

## Контракт и проверка

В OpenAPI `PlanCommand` добавлены `insert_infrastructure_stop` (date, place_id, опционально position и observed_at) и `edit_route` (date, text). Используются существующие endpoints preview/apply.

Go-тесты проверяют историю, GPS-расход, другие дни, дубли, права владельца, отсутствие записи при preview и конфликт версии. `node scripts/smoke-map-actions.mjs` проверяет живые сервисы: три аптеки PostGIS → OSM-заход → apply → текстовое удаление.

## Панель карты

Сценарии срочных действий показаны плитками. Под ними после выбора — до трёх разных ближайших объектов списком с названием, адресом и расстоянием; короткие страницы и дубли ID не останавливают поиск раньше времени. Если в каталоге меньше трёх подходящих объектов, фиктивные результаты не добавляются. Под фильтрами карты находится широкая кнопка «Детский режим». Кнопка со стрелкой сворачивает и разворачивает панель, карта меняет размер. Погодная анимация ограничена одним блоком в левом верхнем углу: одно облако, дождь/снег или солнце по прогнозу.
