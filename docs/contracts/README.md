# Контракты API

- [openapi.json](openapi.json) — основной машинно-читаемый контракт OpenAPI 3.1.1: публичный backend API, внутренние ML API, схемы, параметры, авторизация и ответы.
- [integration_contracts_v1.md](integration_contracts_v1.md) — ответственность команды, сценарии и бизнес-инварианты, не выражаемые только схемой.
- [contracts_v1.ts](contracts_v1.ts) — вспомогательный снимок DTO; автоматическая генерация из OpenAPI ещё не настроена.
- [Задание для ML по обогащению данных](../data_enrichment_ml_task.md) — назначение каталога, поля и веса, источники, правила качества и ожидаемый результат.
- Go-модели генерируются в `internal/contracts/models.gen.go` командой `node scripts/generate-go-contracts.cjs`, затем `gofmt -w internal/contracts`. Это генерация моделей, не клиентов HTTP.

Спецификация в статусе draft и содержит целевой объём API. Реализованы базовые операции поездки, многодневный планировщик и HTTP-адаптер ML; остальные операции остаются проектом. ML возвращает до 50 разных мест на всю поездку, backend Максима отвечает за распределение, маршрут OSM и итоговую выполнимость. Точный текущий объём и запуск описаны в корневом README. HTTP-форматы меняются сначала в OpenAPI, затем синхронизируются с пояснениями и клиентскими типами. JSON — поддерживаемый формат OpenAPI; дублировать тот же контракт вручную в YAML не требуется.

Публичные операции помечены тегом Public Backend, закрытые — Internal ML. Общий документ описывает интерфейсы разных провайдеров: внутренние endpoints не следует публиковать на внешнем backend.

Bootstrap гостевой сессии и CSRF реализованы. Финальный валидатор backend соответствует подтверждённой границе ответственности. Целевая политика балансировки и коэффициент интересов взрослых остаются предложенными деталями MVP. Спецификация не означает, что все endpoints уже реализованы.

Локально проверены JSON, разрешение ссылок компонентов, уникальность operationId, обязательные path-параметры и соответствие схем DTO. Полная проверка специализированным валидатором OpenAPI и генерация Go/TypeScript клиентов пока не выполнены.
