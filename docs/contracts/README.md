# Контракты API

- [openapi.json](openapi.json) — основной машинно-читаемый контракт OpenAPI 3.1.1: публичный backend API, внутренние ML API, схемы, параметры, авторизация и ответы.
- [integration_contracts_v1.md](integration_contracts_v1.md) — ответственность команды, сценарии и бизнес-инварианты, не выражаемые только схемой.
- [contracts_v1.ts](contracts_v1.ts) — вспомогательный снимок DTO; автоматическая генерация из OpenAPI ещё не настроена.

Спецификация в статусе draft. HTTP-форматы меняются сначала в OpenAPI, затем синхронизируются с пояснениями и клиентскими типами. JSON — поддерживаемый формат OpenAPI; дублировать тот же контракт вручную в YAML не требуется.

Публичные операции помечены тегом Public Backend, закрытые — Internal ML. Общий документ описывает интерфейсы разных провайдеров: внутренние endpoints не следует публиковать на внешнем backend.

Bootstrap гостевой сессии и CSRF, целевой баланс активностей, коэффициент интересов взрослых и финальный валидатор backend — предложенные решения для MVP, требующие согласования командой. Спецификация не означает, что endpoints уже реализованы.

Локально проверены JSON, разрешение ссылок компонентов, уникальность operationId, обязательные path-параметры и соответствие схем DTO. Полная проверка специализированным валидатором OpenAPI и генерация Go/TypeScript клиентов пока не выполнены.
