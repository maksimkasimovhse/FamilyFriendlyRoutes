# Помощник: реализованный контракт

Статус на 21 ноября 2026 года: публичная ручка реализована в Go backend,
понимание сообщений выполняет GigaChat через parser-service. Автоматический
переход на `assistant-mock.js` из рабочего фронтенда удалён.

Источник типов — `openapi.json` и `contracts_v1.ts` в этой папке.
[Сценарии, устройство, запуск и проверки](../llm_assistant.md).

## POST /api/v1/trips/{trip_id}/assistant/messages

Нужны cookie сессии, `X-CSRF-Token`, `Content-Type: application/json`;
рекомендуется `Idempotency-Key`. Сервис проверяет владельца поездки и версию.

```json
{
  "expected_version": 3,
  "date": "2030-06-15",
  "message": "Ребёнок устал, давайте покороче",
  "current_position": null,
  "observed_at": "2030-06-15T10:00:00+03:00"
}
```

Ответ 200: `reply`, `preview` (`PlanPreview` или null), `places` (до трёх `Place`),
`options` (place_id, секунды подхода и отклонения), `suggestions` (до пяти строк),
`needs` (тип, child_id, срочность и цитата), `mode="gigachat"`.

Изменение Trip происходит только после пользовательского применения preview
существующей ручкой `/previews/{preview_id}/apply`. Предупреждения требуют явного
подтверждения. Невыполнимый вариант имеет `can_apply=false`.

Контекст относится к конкретной поездке, ограничен шестью обменами репликами и
30 минутами; смена версии Trip сбрасывает варианты. «Давай второй» выбирает место
из сохранённых вариантов и создаёт preview. Параллельная смена версии/контекста —
409, неверные параметры — 422, некорректный ответ LLM — 502, отказ сервиса — 503.
Ошибки не подменяются ответами по ключевым словам.
