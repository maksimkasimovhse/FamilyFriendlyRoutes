# Помощник (ИИ-чат) — черновик контракта [Предложение]

**Архив:** отдельная вкладка помощника удалена. Этот несогласованный endpoint не используется. Актуальная реализация — [действия на карте](../map_actions.md), команды `insert_infrastructure_stop` и `edit_route` в OpenAPI.

Статус: **черновик фронтенда, не согласован**. Сервис — зона Вильдана, публичная ручка — у backend.
Пока ручки нет, фронт отвечает моком на правилах (`frontend/js/assistant-mock.js`) с пометкой «демо».
Фронт сначала вызывает ручку ниже; при `404` переключается на мок — после реализации ничего менять не нужно.

## `POST /api/v1/trips/{trip_id}/assistant/messages`

Те же правила, что у остальных POST: cookie сессии, `X-CSRF-Token`, `Content-Type: application/json`.
Ручка **не изменяет Trip**: изменение маршрута возвращается как обычный `PlanPreview`,
сохраняет его пользователь через существующий `POST /previews/{preview_id}/apply`.

Запрос:

```json
{
  "expected_version": 3,
  "message": "Ребёнок устал, давайте покороче",
  "current_position": null,
  "observed_at": "2026-11-21T13:05:00.000Z"
}
```

Ответ `200`:

```json
{
  "reply": "Понимаю. Давайте сократим прогулку с конца, а следующую точку оставим.",
  "preview": { "...": "PlanPreview — как из POST /previews, или null" },
  "places": [ { "...": "Place — как в MapResponse.items (туалеты, кафе, площадки рядом)" } ],
  "suggestions": ["Нужен туалет", "Хотим поесть"]
}
```

| Поле | Смысл |
|---|---|
| `reply` | Текст ответа, русский, без markdown |
| `preview` | Предложенное изменение маршрута (`PlanCommand` → `PlanPreview`), либо `null` |
| `places` | До 3 мест рядом (схема `Place`), либо `[]` |
| `suggestions` | 0–5 быстрых ответов-подсказок для кнопок |

Ошибки — общий формат `Error`; `409 VERSION_CONFLICT`, если поездка изменилась.

## Что сервис должен уметь (минимум для демо)

- «Ребёнок устал / сократи» → `remove_stop` с конца дня (или `shorten_day`, когда backend его реализует).
- «Убери <точку>» / «пропусти следующую» → `remove_stop`.
- «Опаздываем / пересчитай» → `replan_day`.
- «Туалет / поесть / площадка / дождь» → `places` из каталога рядом с `current_point`.
- «Перенеси на завтра» → когда backend поддержит перенос между днями (`update_trip_input` / новые команды).

Реализовано в backend сейчас: `generate_plan`, `start_day`, `remove_stop`, `replan_day`.
