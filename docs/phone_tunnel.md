# Ссылка на приложение для телефона без сертификата

Cloudflare Quick Tunnel публикует приложение по временной HTTPS-ссылке `https://….trycloudflare.com`. Телефону нужны браузер и интернет; установка сертификатов и одна Wi-Fi-сеть не требуются. Компьютер и Docker должны оставаться включёнными.

Ссылка публичная: запросы приложения, включая вход и анкету, проходят через Cloudflare. Сессии, авторизация владельца поездки и CSRF продолжают проверяться backend. Это режим демонстрации, не постоянный адрес продукта.

## Запуск

Из корня репозитория с настроенным `.env`:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-phone-tunnel.ps1
```

Скрипт запускает backend/web и профиль Compose `tunnel`, ждёт зарегистрированного соединения и печатает ссылку. Если backend уже собран, добавить `-SkipBuild`. Ссылка также сохраняется в `data/backend/phone-tunnel-url.txt` (игнорируется Git). После перезапуска контейнера ссылка может измениться.

На телефоне открыть ссылку, нажать «Где я» или срочный сценарий и разрешить доступ к геопозиции. Геолокация всё равно требует разрешения браузера/системы; HTTPS обеспечивает возможность такого запроса.

## Остановка и диагностика

```powershell
docker compose --profile tunnel stop cloudflared
docker compose --profile tunnel logs --tail 80 cloudflared
```

Не создаются входящие порты на роутере или Windows. Служба использует исходящее соединение Cloudflare с автоматическим выбором QUIC/HTTP2 (UDP/TCP 7844); если сеть его блокирует, туннель не подключится. При проблемах проверить доступность Cloudflare из текущей сети и журнал контейнера. Временные туннели не имеют гарантий доступности; для постоянного адреса нужен именованный туннель/домен.

## Прокси и проверка

`cloudflared → web:8001 → backend:8080`. Внутренний порт nginx 8001 не опубликован и выставляет HTTPS-протокол для доверенного backend. Оригинальный Host сохраняется для проверки Origin; cookie имеют Secure-флаг. Локальный `http://localhost:8000` остаётся доступным для разработки.

```powershell
node scripts/smoke-phone-tunnel.mjs
```

Проверка использует доверенные публичные CA, без обхода TLS; проверяет страницу, SVG, Secure-cookie, CSRF и отклонение неверного Origin. Создаёт тестовый черновик в отдельной гостевой сессии.

[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/), [параметры подключения](https://developers.cloudflare.com/tunnel/reference/run-parameters/).
