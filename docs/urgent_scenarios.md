# Срочные сценарии семьи

Актуальный UI и изменение маршрута: [map_actions.md](map_actions.md). Вкладка помощника удалена; вход — кнопка «Нужно сейчас» на карте.

Кнопки работают через `frontend/js/urgent-actions.js`, без запроса к ML/чат-сервису и без мокового поиска. Объекты берутся из PostgreSQL через существующий `GET /api/v1/map/places` с категориями и `nearest=true&limit=3`, без ограничения расстоянием. Поиск начинается только после действия пользователя; геопозиция не заменяется стартом, отелем или следующей остановкой. При отказе в доступе выводится ошибка и возможность повторить действие.

| Кнопка | Конкретное действие |
|---|---|
| Ребёнок устал | Три ближайшие скамейки от GPS без ограничения расстоянием. Если их нет, предложить поиск кафе или отдельный пропуск точки. Ничего автоматически не удалять. |
| Нужен туалет | Три ближайших туалета от GPS без ограничения расстоянием. |
| Хотим поесть | Три ближайших ресторана/кафе от GPS без ограничения расстоянием. Семейные признаки показаны в карточке; сортировка по расстоянию. Неизвестные признаки не считаются подтверждёнными. |
| Пошёл дождь | Три ближайших подходящих места без ограничения расстоянием: помещения, укрытия и кафе, с сохранением сортировки по расстоянию. Кафе без данных предлагаются с подписью «возможность укрыться не подтверждена»; кафе с явно отрицательным признаком помещения не считаются укрытием без отдельного положительного признака навеса. |
| Аптека | Три ближайшие аптеки от GPS без ограничения расстоянием. |
| Площадка | Три ближайшие детские площадки от GPS без ограничения расстоянием. |
| Пропусти следующую точку | Первая `planned` остановка, обязательную не удалять. Расчёт от последней подтверждённой позиции без запроса GPS. Preview показывает разницу и предупреждения; сохранение по «Применить». История сохраняется. |

Список показывает название и расстояние по прямой. Нажатие на «Зайти сюда» сразу рассчитывает preview маршрута через место по OSM. До подтверждения новый маршрут не сохраняется. Наличие объекта в базе не подтверждает, что он открыт сейчас.

Лавочки исключены из инфраструктуры вдоль маршрута. На карте они загружаются отдельным запросом только вокруг GPS в радиусе 125 м после нажатия «Где я» или сценария отдыха. Кнопка «Где я» включает обновление положения; старые запросы не могут вернуть лавочки у предыдущей позиции. Без геопозиции лавочки не показываются. Обычные метки прореживаются: сначала ближайшая к GPS, затем только скамейки минимум в 50 м от уже оставленных. Исходные данные и результаты срочного поиска не прореживаются. Остальные категории — в коридоре 125 м от сохранённого маршрута.

Срочные сценарии используют отдельный режим `lon+lat+nearest=true`, несовместимый с `radius_km` и `bbox`. Бэкенд сортирует всю опубликованную базу по геодезическому расстоянию. Если первые объекты не подходят (например, открытое кафе для дождя), клиент продолжает страницы до трёх подходящих или конца каталога. Добавление инфраструктуры в маршрут реализовано через preview/apply. Автоматическое погодное перестроение не реализовано.

Проверка: `node --test frontend/js/places.test.mjs frontend/js/recommendation-cards.test.mjs frontend/js/urgent-actions.test.mjs frontend/js/place-display.test.mjs`.
