# Миниатюры объектов карты

Восемь оригинальных PNG с прозрачностью, 192×192, созданы через imagegen для этого проекта. Используются через `frontend/js/place-display.js`: карта, остановки, «Сегодня», карточки выбора и срочных сценариев. Обозначение еды — тарелка с котлетой и картофельным пюре; само изображение не подтверждает наличие детского меню у заведения.

`food`, `toilet`, `playground`, `park`, `bench`, `pharmacy`, `landmark`, `event`. `museum` использует `landmark`, `theatre` использует `event`. Исходные генерации остаются в локальном каталоге Codex; готовые изображения проекта полностью находятся здесь. Контактный лист: `docs/assets/map-icons-preview.png`.

На карте картинки отрисовываются как текстуры с прозрачностью, без эмодзи и цветных подложек. У остановок отдельный номер порядка и отметка посещения. Логика отбора объектов и прореживания скамеек от внешнего вида не зависит.
