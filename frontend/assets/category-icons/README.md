# Значки категорий

Текущий набор интерфейса: цветной круг с мягким объёмом, внутренним ободком и белым символом. Оригинальные SVG, 80×80, без внешних зависимостей. Еда — бирюзовая, туалеты — синие, площадки — оранжевые, парки — зелёные, лавочки — коричневые, аптеки — красные, музеи — фиолетовые, события — розовые. Категория по умолчанию — синий значок места.

Применяется на карте, в фильтрах, карточках и срочных сценариях через `frontend/js/place-display.js`. Совместимые имена функций `emojiAsset`, `placeEmojiHtml` и `createPlaceEmoji` теперь возвращают SVG этого набора. Предыдущие PNG-наборы не используются интерфейсом.

`preview.html` показывает все значки в большом и фактическом маленьком размере. Прореживание скамеек и логика подбора объектов не меняются.
