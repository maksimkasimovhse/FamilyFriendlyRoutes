# Первый OSM-снимок для обогащения

Снимок содержит ровно 1 000 точек OpenStreetMap в рабочей зоне Нижнего Новгорода. Он построен 20 ноября 2026 года из локальной выгрузки Geofabrik `volga-fed-district-261117.osm.pbf` и предназначен для следующего этапа: поиска и парсинга официальных страниц.

- `catalog.jsonl` — нормализованные места, активности, evidence и полный набор исходных OSM-тегов.
- `parsing_queue.csv` — очередь для официального парсинга; 194 строки уже содержат URL из OSM.
- `source_dataset_mapping.csv` — сопоставление всех 259 строк переданного культурного CSV с OSM-каталогом. 116 совпадений найдены только по равному имени или расстоянию не более 80 м; остальные сознательно не склеены.
- `coverage_report.json` — измеренное покрытие и ограничения снимка.
- `source_discovery_queue.csv` — URL-кандидаты из OSM, Wikidata P856 и явно названные в ТЗ источники; это очередь на проверку источников, а не разрешение на обход.
- `source_registry_candidates.json` — отключённый шаблон allowlist для проверенных доменов. Источник разрешается для парсинга только после ручной проверки ownership, robots.txt и редиректов.
- `wikidata_p856_cache.json` — воспроизводимый снимок поля «официальный сайт» (P856), полученный из Wikidata. Для сетей выбирается только российский домен либо один нейтральный кандидат, а не список сайтов всех стран.

Поля, отсутствующие в OSM, остаются `unknown`: возрастные правила, рекомендованный возраст, продолжительность, детское меню и игровые зоны, фактические сеансы, а также проверенное расписание. Отсутствие OSM-тега не трактуется как `false`. Для данного прохода извлекались только OSM-узлы, поэтому крупные объекты, размеченные полигонами (в частности, часть парков), попадут в отдельный geometry-проход.

Повторить сбор с присланным CSV:

```bash
python scripts/build_osm_enrichment_catalog.py \
  --seed "/home/votter/Загрузки/Туризм/Туризм/_select_cs_id_cs_address_cs_coordinate_cs_description_cs_title_c.csv"

python scripts/build_source_discovery_queue.py
# Обновить снимок P856 из Wikidata:
python scripts/build_source_discovery_queue.py --refresh-wikidata
```
