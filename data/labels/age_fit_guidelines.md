# Разметка возрастной пригодности

Единица разметки — конкретная активность и одна группа возраста: `activity_id × age_band`. Место с несколькими программами получает разные `activity_id`; нельзя переносить возрастную пригодность одной программы на всё место.

Сначала размечается фактический допуск `participation_allowed`:

- `forbidden` — есть проверенный запрет; `age_fit` оставляется пустым;
- `allowed` — участие разрешено или явно предусмотрено;
- `unknown` — надёжного правила допуска нет.

`age_fit` описывает удобство и содержательную уместность активности для ребёнка, если жёсткого запрета нет. Для согласованности используется шкала:

| Значение | Интерпретация |
| --- | --- |
| 1.00 | группа явно целевая для активности |
| 0.75 | хорошо подходит, хотя не единственная целевая группа |
| 0.50 | в целом подходит, но есть заметные возрастные компромиссы |
| 0.25 | участие возможно, однако формат в основном рассчитан на другой возраст |
| 0.00 | формально участвовать можно, но содержательно активность не подходит |
| пусто | доказательств недостаточно |

Рейтинг места, популярность и сам факт упоминания возраста в отзыве не являются меткой. Предпочтителен официальный источник на конкретную программу; отзыв служит подсказкой для поиска и требует проверки. `evidence_url`, проверяющий и время проверки обязательны. Для итогового датасета желательно две независимые оценки; расхождение больше 0.25 требует разбора до публикации согласованной строки.
