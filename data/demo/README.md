# Демонстрационный каталог

Файлы генерируются из `db/seed/main.csv` командой:

```bash
PYTHONPATH=models:. python scripts/prepare_demo_catalog.py
```

- `catalog.jsonl` — 40 ближайших к туристическому центру объектов с балансом категорий;
- `coverage_report.json` — измеренная заполненность важных полей;
- `parsing_queue.csv` — очередь поиска и парсинга официальных страниц.

Темы и форматы в первом срезе получены прозрачными keyword-правилами и помечены
`heuristic_model`. Возрастная пригодность, длительность, часы и URL не выводятся из общего
описания и остаются неизвестными до проверки источника.

Активный каталог расширен до 281 объекта и находится в `data/catalog/city/`.
Этот срез из 40 записей сохранён как исходный экспериментальный fixture.
Аудит и решения отбора: `data/catalog/README.md`.
