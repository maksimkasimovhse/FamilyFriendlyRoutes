# OSM-инфраструктура Нижнего Новгорода

`osm-infrastructure.geojson` — реальные данные из локального OSM PBF, не генерация и не демо-факты. Выгрузка включает площадки, парки, скамейки, туалеты, аптеки и кафе/рестораны. Источник, дата и bbox указаны в самом файле. Лицензия: Open Database License (ODbL) 1.0, © OpenStreetMap contributors.

Не проверено на месте. Для площадных объектов координата — центр bbox, не вход. Relations не включены. Записи `access=private/no` исключены. Это область вокруг Нижнего, не точная муниципальная граница.

Импорт, API и обновление: [docs/map_infrastructure.md](../../docs/map_infrastructure.md). Секреты и дамп БД в этот каталог не помещать.
